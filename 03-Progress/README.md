# 03-Progress · 答题记录与错题本

> 目录职责：**只记录「你答了什么、错在哪、什么时候再问」**。
> 知识点本身不写这里，写在 `01-notes/`；题目本身不写这里，写在 `04-interview/question-bank/`。

## 一、和现有目录的对应关系

| 原规则目录 | 本仓库实际位置 | 说明 |
| :--- | :--- | :--- |
| `01-Knowledge` | `01-notes/stageX-*/WNN-*.md` | 已有 12 份周笔记，按 W 编号 |
| `02-Questions` | `04-interview/question-bank/*.md` | 已有 8 个题库文件（Java基础 24 题、Java并发 12 题等） |
| `03-Progress` | **本目录** | 新建。`03-project/` 已占用 03 前缀，故并列存在 |
| `04-Projects` | `03-project/` | 长期项目「异步任务管理平台」 |

> 不动老目录结构的原因：NoteSync 已同步到 GitHub、iPad 在读，重命名会断掉大量笔记里的相对路径引用。
> 若确实要统一编号，一次性改名即可，届时同步修改引用。

## 二、每道题必须留的七个字段

| 字段 | 含义 |
| :--- | :--- |
| 题目 ID | `W03-D3-01` = 第 3 周 Day 3 第 1 题；面试训练用 `MI-20261106-01` |
| 日期 | 首次作答日期 |
| 用户答案 | **原话照抄**，不要事后美化 —— 错因往往藏在措辞里 |
| 正确答案 | 要点式，不抄教材 |
| 错误原因 | 必须归到「概念错 / 记混 / 漏了前提 / 会但说不出」四类之一 |
| 掌握度 | 0 不会 / 1 有印象说不清 / 2 能讲但有漏洞 / 3 脱稿通过 |
| 下次复习 | 掌握度 0→次日，1→3 天后，2→7 天后，3→21 天后 |

## 三、硬规则

1. **读过 ≠ 掌握。** 笔记里写过、代码跑过的点，仍按掌握度 0 起算，答对一次才 +1。
2. **历史错题不删。** 答对了就在同一行追加复习记录，掌握度升级，原答案保留。
3. **未验证的技术结论标「待验证」。** 尤其是「我记得 JDK 是这样」这类 —— 要么 `javap` / 跑一遍，要么标上。
4. 每次复习优先挑：掌握度 ≤ 1 且到期日已到的题。
