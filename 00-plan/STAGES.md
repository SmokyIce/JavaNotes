# 阶段目标与能力矩阵

## 第一阶段 · 打基础（W01–W12）· 8K → 15K

- **主题**：Java → Spring → MySQL → Redis 四件套打透
- **目标**：能独立做模块、能解释原理；同时启动长期项目
- **产出**：第 1 个月：Java 基础 + 10 道自己的代码练习｜第 2 个月：Spring 事务 / AOP Demo｜第 3 个月：MySQL 索引实验 + 10 条 EXPLAIN 案例
- **目录**：`01-notes/stage1-basics/`　`02-code/stage1-basics/`

## 第二阶段 · 进阶提升（W13–W24）· 15K → 20K

- **主题**：JVM + Redis 进阶 + MQ + 并发 + Linux + Docker
- **目标**：能解决线上复杂问题，能自己登服务器排障
- **产出**：第 4 个月：Redis 缓存 Demo｜第 5 个月：JVM 排查实验｜第 6 个月：RabbitMQ 任务系统
- **目录**：`01-notes/stage2-advanced/`　`02-code/stage2-advanced/`

## 第三阶段 · 系统设计（W25–W40）· 20K → 25K

- **主题**：微服务 + 高并发 + 性能优化 + 系统设计
- **目标**：从「会用技术」变成「会设计系统」
- **产出**：第 7–9 个月：微服务版任务系统
- **目录**：`01-notes/stage3-system-design/`　`02-code/stage3-system-design/`

## 第四阶段 · 面试冲刺（W41–W48）· 能力 → Offer

- **主题**：整理能力 + 面试 + 项目包装 + 查漏补缺
- **目标**：把前 40 周的能力转化成面试结果
- **产出**：第 10–12 个月：完整项目 + 技术文档 + 面试题库 + 简历
- **目录**：`01-notes/stage4-interview/`　`02-code/stage4-interview/`
