**追问预判：**

### 2. HashMap 的扩容机制？为什么扩容后元素位置只有两种可能？

**我的回答（自己的话）：**

**追问预判：**
- 什么时候扩容？（`++size > threshold`，**严格大于**；容量 16 阈值 12，第 13 个才触发）

### 3. Java 成员变量和局部变量的默认值有什么区别？
