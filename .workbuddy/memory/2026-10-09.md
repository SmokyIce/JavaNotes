**实测关键数字**

| 观测点 | 结果 |
| :--- | :--- |
| "hello" 定位 | hashCode 99162322 → 扰动 99163451 → 桶下标 11（容量 16） |
| 扩容边界 | 16→第13个扩到32；32→第25个扩到64；64→第49个扩到128（阈值 0.75） |
| 扩容后位移 | 旧16→新32，8 个 key 里 5 个 "+16"、3 个"不动" |
| 冲突对 | "Aa" 与 "BB" hashCode 均为 2112，同桶但 equals=false |
| put 覆盖 | put(k,100)→null；put(k,200)→100；size 恒为 1 |

**两个额外解决的问题（学员提问驱动，均已进笔记）**

1. `MyArrayList` 的 `size` 找不到初始化处 → **成员变量由编译器补默认值**（int=0，引用=null）；
   JVM 分配对象内存时整块归零，发生在构造函数第一行之前。局部变量则必须手动初始化。
   连带记：`new int[10]` 是 `[0,...]`，`new Integer[10]` 是 `[null,...]`。
2. JDK 9+ 反射读 `HashMap.table` 抛 `InaccessibleObjectException`（模块系统不 opens java.util）
   → 方案：启动参数 `--add-opens java.base/java.util=ALL-UNNAMED`；
   代码内加 `probeReflect()` 一次性探测 + `inferCapacity()` 按 size 推算容量兜底，保证不加参数也不崩。
   （`--add-opens` 允许反射 setAccessible，`--add-exports` 只允许直接访问 —— 别混。）
