**实测关键数字（JDK 17.0.12）**

| 操作 | ArrayList | LinkedList | 比值 |
| :--- | ---: | ---: | ---: |
| add(E) 尾插 | 44 ns/op | 161 ns/op | 3.66x 慢 |
| get(i) 随机访问 | 43 ns/op | 6990 ns/op | 163x 慢 |
| for-i 按下标遍历 | 2.97 ns/op | 6711 ns/op | 2263x 慢 |
| iterator 遍历 | 10.6 ns/op | 9.8 ns/op | 0.93x（基本持平） |
| add(0,E) 头插 | 996 ns/op | 56 ns/op | 0.06x（链表快 18x） |
| add(mid,E) 中间插 | 487 ns/op | 7634 ns/op | 15.7x 慢 |
| remove(0) 头删 | 895 ns/op | 25 ns/op | 0.03x（链表快 36x） |
| 内存（100 万元素） | 4.00 MB | 22.91 MB | 5.7x |

三个反直觉点（已写进笔记）：链表尾插也慢于数组；“链表遍历慢”是伪命题（慢在 get(i) 不在遍历）；链表插入快的前提是“已经拿到节点”，业务代码里几乎不成立 → 默认用 ArrayList，两端操作用 ArrayDeque。
