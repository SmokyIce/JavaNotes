## 关键数字
- `refresh` 后构造数：singleton `1` / prototype `0`；两次 `getBean` 的 `==`：`true` / `false`
- `containsSingleton`：`true` / `false`；`close()` 后 `@PreDestroy`+`destroy`：`1+1` vs `0+0`
- `registerScope("singleton", …)` → `IllegalArgumentException: Cannot replace existing scopes 'singleton' and 'prototype'`（`AbstractBeanFactory:1045`）
- `getRegisteredScopeNames()` = `[thread]`；`SimpleThreadScope`：main 两次同实例、worker-A 另一实例（共 2 个），并打 WARN「不支持销毁回调」
- `request` → `IllegalStateException: No Scope registered for scope name 'request'`，`doGetBean:369`；**refresh 不报、getBean 才报**
- proxyMode：无代理三次 `id()` = `1/1/1`（造 1 个）；`TARGET_CLASS` 后 = `2/3/4`（造 3 个）
- 定义被拆两个：`scopedTarget.requestProxy`（`scope=request`, `factoryMethod=requestProxy`）+ `requestProxy`（`class=ScopedProxyFactoryBean`, 单例）
- `request` + 代理：`getBean` 不抛，首次 `id()` 抛同一 ISE，栈多 `SimpleBeanTargetSource.getTarget:35` ← `CglibAopProxy$DynamicAdvisedInterceptor:691`
- 自定义 `every-two`：4 次 `getBean` = `A A B B`，轮换销毁 1 次，`close()` 后仍 1 次

## 踩坑（5 条）
1. `@Scope`（注解）与 `Scope`（接口）同名 → 同文件 `implements` 必须写全限定名，否则「引用不明确」。
2. `SimpleThreadScope` 没有 `SCOPE_NAME` 常量（作用域名就是字符串 `"thread"`）——又一次按别的类 API 想当然。
3. `AbstractBeanFactory:1942` 是方法声明，`!isPrototype()` 在 **1944** —— 与 Day 2 的 154/157 同病。
4. 第一版写「拆出来的两个定义 class 都为空」→ 错，外层是 `ScopedProxyFactoryBean`，只有真身（`@Bean`）没有 class。
5. 第一版写「`close()` 会通知 scope」→ 错，`close()` 只销毁单例；自定义作用域得自己收尾。
