# 学习笔记

按阶段分目录，**每周一份 Markdown**，文件名格式 `W{周号}-{主题}.md`。

| 目录 | 阶段 | 周次 |
| :--- | :--- | :--- |
| `stage1-basics/` | 第一阶段 · 打基础 | W01–W12 |
| `stage2-advanced/` | 第二阶段 · 进阶提升 | W13–W24 |
| `stage3-system-design/` | 第三阶段 · 系统设计 | W25–W40 |
| `stage4-interview/` | 第四阶段 · 面试冲刺 | W41–W48 |

## 写笔记的三条底线

1. **用自己的话写**，不要复制粘贴教程原文。
2. 「核心问题」一栏必须能脱稿讲出来，讲不出来就是没学会。
3. 每天留一行「每日打卡」，周末补「一句话总结」。

新建某一周笔记时，可以直接复制 `05-resources/templates/周笔记模板.md`。
