# 第二阶段 · 进阶提升 · 代码（W13–W24）

JVM + Redis 进阶 + MQ + 并发 + Linux + Docker

## 命名约定

- 目录名全部用小写 ASCII：`w{周号}-{主题英文}`，例如 `w01-collections`
- Java 包名对应：`com.newt.java48.w01`
- 每周一个独立可运行的工程（Maven / Gradle），能单独 `mvn test` 跑起来
- 跨周复用的 Demo 放 `../lab/`；项目代码放 `../../03-project/`
