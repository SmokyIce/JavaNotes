48      64      48          48     
49      128     96          49     ← 扩容 64 → 128 ｜ size 49 > 阈值 48，size 触发
50      128     96          50     

两个触发条件的区别：
  · size 触发：元素总数超了容量承载能力 → 整表翻倍（16→32→64→128…）
  · 链表触发：个别桶太挤，但容量还不到 64 → 也翻倍（可避免过早树化）
  两条路走的都是同一个 resize()，所以容量永远是 2 的幂。
