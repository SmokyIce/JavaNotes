 四、synchronized 方法：只有 ACC_SYNCHRONIZED 标志，没有 monitorenter

    flags: (0x0020) ACC_SYNCHRONIZED

     这就是 Day 2 那条被打脸的「想当然」：方法级同步不加指令，改的是方法访问标志。

 五、ReentrantLock：调用方看到的就是一次普通方法调用
     （LockCompare 里的 lock.lock()）
------------------------------------------------------------------
       1: invokevirtual #282                // Method java/util/concurrent/locks/ReentrantLock.lock:()V
      67: invokevirtual #290                // Method java/util/concurrent/locks/ReentrantLock.unlock:()V
      91: invokevirtual #290                // Method java/util/concurrent/locks/ReentrantLock.unlock:()V
     100: invokevirtual #290                // Method java/util/concurrent/locks/ReentrantLock.unlock:()V

     三种写法的字节码差别，比它们的性能差别小得多：
     synchronized → monitorenter（JVM 指令）；ReentrantLock → invokevirtual（Java 方法）；
     手写 AQS → 同样的 invokevirtual，只是方法体里多了 park/unpark。
