## 约定

- **命名**：`w{周号}-{主题英文}`，全小写 ASCII，例如 `w01-collections`。
  （目录名不用中文 —— Java 包名、Maven 构建路径都要求 ASCII，避免踩编码坑。）
- **每周一个独立工程**，能单独 `mvn test` 跑起来，不依赖其他周。
- **包装**：`com.newt.java48.w01`，与目录一一对应。
- **不改历史**：完成的那一周不再回头改，新学到的写法放到当周或 `lab/` 里对比。
