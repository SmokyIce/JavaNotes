# 异步任务管理平台

贯穿 48 周的长期项目。第 8 周起步，之后每周往里加东西，避免「学了一堆技术但没有一个完整项目」。

## 架构演进

```text
第 1 阶段（W08-W24）  单体：Vue → Spring Boot → MySQL → Redis → RabbitMQ → Worker
第 2 阶段（W24）      容器化：全部跑在 Docker / docker-compose 里
第 3 阶段（W25-W40）  微服务：Gateway + 服务拆分 + 限流熔断 + 缓存架构
第 4 阶段（W41-W48）  包装：架构图 + 技术文档 + 五大难题复盘
```

## 功能清单

- [ ] 创建任务
- [ ] 任务执行
- [ ] 任务进度
- [ ] 任务失败
- [ ] 任务重试
- [ ] 任务取消
- [ ] 任务日志
- [ ] 任务恢复

## 目录

| 目录 | 用途 | 启用时间 |
| :--- | :--- | :--- |
| `docs/` | 需求 / 架构 / 数据库 / 流程 / 接口 | W08 起 |
| `task-core/` | 单体版服务（Spring Boot） | W08 起 |
| `deploy/` | Dockerfile、docker-compose、部署脚本 | W23 起 |
| `microservices/` | 拆出来的网关与各服务 | W25 起 |

## 各阶段往项目里加什么

| 阶段 | 新增能力 |
| :--- | :--- |
| 第 1 阶段（W08 起） | 基础任务提交与执行、`@Async` 异步、任务状态落库 |
| 第 2 阶段 | Redis 缓存与分布式锁、RabbitMQ 解耦、重试与死信、幂等、Docker 化部署 |
| 第 3 阶段 | 服务拆分、网关、限流熔断、缓存架构、深分页与性能优化 |
| 第 4 阶段 | 项目包装、难题复盘、架构图与技术文档 |
