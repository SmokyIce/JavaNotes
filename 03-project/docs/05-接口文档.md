# 05 · 接口文档

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| POST | /api/task | 创建任务 |
| GET | /api/task/{id} | 查询任务 |
| GET | /api/task/{id}/progress | 查询进度 |
| POST | /api/task/{id}/cancel | 取消任务 |
| POST | /api/task/{id}/retry | 重试任务 |
| GET | /api/task/{id}/logs | 任务日志 |

## 示例

```json
POST /api/task
{
  "name": "demo-task",
  "payload": {}
}
```
