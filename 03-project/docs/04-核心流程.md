# 04 · 核心流程

## 任务创建 → 执行 → 完成

```text
提交任务 → 落库(PENDING) → 投递 MQ / @Async → Worker 执行
        → 更新进度(RUNNING) → 成功(SUCCESS) / 失败(FAILED)
        → 重试 / 死信 / 人工恢复
```
