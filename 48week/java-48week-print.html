四条执行铁律

#规则具体怎么做
1输入必留 15 分钟输出学完 Spring 事务，关掉资料自己写：事务是什么 / Spring 怎么实现 / @Transactional 为什么失效 / REQUIRES_NEW 做什么 / this.xxx() 为什么失效。能自己答出来才算学会。
2Bug 修完别关 IDE修完 @Async 事务失效，再花 20–30 分钟问：为什么 / 底层原理 / 还有哪些情况会失效 / 面试怎么问 / 能不能写 Demo 复现。
3项目从第 8 周开始长异步任务管理平台：创建 / 执行 / 进度 / 失败 / 重试 / 取消 / 日志 / 恢复。后 40 周持续往里加 Redis、MQ、Docker、微服务。
4追求 300 天后还在学不追求每天学很多。哪怕当天只搞懂「为什么 this.xxx() 会导致事务失效」，这一天也成立。持续性压倒强度。
